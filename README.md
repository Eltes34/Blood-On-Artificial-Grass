# Blood-On-Artificial-Grass
Цзян Му просыпается в незнакомом тёмном городе. Рядом — её испуганная сестра Мао Ли. Вскоре они узнают, что попали в один из «номеров» — загадочных миров, связанных с коробками с цифрами. Здесь действуют жестокие правила: каждого, кто не выполнит условия «хранителя номера», ждёт смерть, причём настоящая — и в этом мире, и в реальности.
